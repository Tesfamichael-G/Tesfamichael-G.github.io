This course equips students with Object-Oriented Programming (OOP) concepts in Java to turn complex code into relatable "objects." Develops advanced problem-solving skills through the study of algorithm design techniques and complexity analysis. ECEG 4192

Data Structures

Builds essential programming skills through the study of fundamental data structures and their implementations. Students learn to work with linear structures (arrays, linked lists, stacks, queues), hierarchical structures (trees, heaps, binary search trees), and network structures (graphs). The course emphasizes understanding when and why to use each data structure, analyzing their performance characteristics, and implementing them in C++ or Java. Students also explore hashing techniques, sorting algorithms, and complexity analysis. This course provides the critical foundation for writing efficient, scalable software and succeeding in advanced computer science courses.
